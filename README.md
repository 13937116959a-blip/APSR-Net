# Attribute-Guided Progressive Semantic Refinement Network for Camouflaged Object Detection

## 📌 Introduction

This repository is for APSR-Net, an Attribute-guided Progressive Semantic Refinement Network for camouflaged object detection (COD).

Camouflaged object detection: CAMO, CHAMELEON, COD10K, and NC4K.

Polyp segmentation: Kvasir-SEG, CVC-ClinicDB, CVC-300, CVC-ColonDB, ETIS-LaribPolypDB, and CPSD2K.
